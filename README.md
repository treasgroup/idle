# «Что приготовить?»

Сервис, который подбирает домашние рецепты по продуктам, времени и настроению и закрывает остальные кухонные задачи: меню на неделю без остатков, список покупок, продукты «Дома» со сроками годности, режим готовки по шагам, школа для начинающих. Работает целиком на своём сервере (PHP + SQLite) и в браузере, без платного ИИ и платных API.

## Структура

```
server/   то, что лежит на хостинге (корень сайта https://shefly.ru): PHP API, страницы для поисковиков, боты, каталог, собранный фронтенд
web/      исходники фронтенда (React + TypeScript + Vite + Tailwind); сборка пишется прямо в server/
```

* `server/api/` — API (`index.php?r=…`): сессии, аккаунты без регистрации, семья, опросы, отзывы, напоминания (web push), статистика, админка.
* `server/data/catalog/*.json` — рецепты партиями; `?check=1` на сайте показывает, что принято и что отклонено.
* `server/recipe.php`, `recipes.php`, `combo.php`, `sitemap.php` — страницы для Яндекса и Google: рецепт, списки, «что приготовить из X и Y».
* `server/bot/telegram.php`, `server/bot/alice.php` — Telegram-бот и навык Алисы.
* `server/admin/` — админ-панель (прежняя сборка, `assets/legacy/`).
* `web/src/engine/` — движок подбора: разбор фраз, подбор и ранжирование, КБЖУ, меню, покупки, сроки хранения. Перенесён из прежней сборки сайта без изменений логики; читаемые имена и типы — в `web/src/engine/index.ts`.
* `web/src/screens/` — экраны: Сегодня (помощник), Рецепты, Рецепт, Готовка, Меню, Покупки, Дома, Профиль, Школа готовки.

## Сборка

```bash
cd web
npm install
npm test          # проверки движка на настоящем каталоге
npm run build     # typecheck + сборка в ../server (старые бандлы удаляются)
```

Для разработки: `npm run dev` (запросы к `/api` проксируются на `https://shefly.ru`, другой адрес — через `COOK_API`).

## Выкладка

1. Соберите фронтенд (`npm run build`).
2. Загрузите содержимое `server/` в корень сайта на хостинге. Файлы `api/_private/config.php` и `api/_private/storage/` на хостинге не трогайте: в них пароль админки и база с данными пользователей, в репозитории их нет.
3. Откройте `сайт/?check=1` и убедитесь, что каталог принят без ошибок.
4. В `assets/` можно удалить старые `app-…` и `chunk-…` файлы, которых нет в новой сборке (папку `legacy/` не трогайте). Если у кого-то открыта старая вкладка, она сама перезагрузится.

Что важно при выкладке: файлы `.htaccess` (в корне и в `ocr/`) должны попасть на хостинг — в них правила безопасности и разрешение для распознавания текста. Папка `ocr/` (≈ 14 МБ) — распознавание фото для «Семейной книги»; людям она загружается только при первом использовании. Копии базы делаются сами раз в день в `api/_private/storage/backups` (последние 7).

Проверка перед выкладкой: `npm run check:site -- https://адрес/` проходит сайт как человек (телефон и компьютер) и сообщает об ошибках. Статистику, аккаунты и уведомления она не трогает.

## Проверки и качество

* `npm test` — 211 проверок движка и экранов на настоящем каталоге (подбор, разбор фраз, меню, покупки, Шеф). `CHEF_BENCH=1 npx vitest run src/__tests__/chefBench.test.ts --silent=false` — прогон 253 живых запросов к Шефу с отчётом.
* GitHub Actions (`.github/workflows/check.yml`) на каждый push: типы TypeScript (`strict`), все тесты, синтаксис PHP и JSON каталога.
* Сервер: все запросы к SQLite — подготовленные; админка — пароль `password_hash`, сессии в httpOnly/SameSite=Strict cookie, ограничение попыток входа, проверка Origin на изменениях; закрытые папки отдают 403; заголовки CSP, HSTS, nosniff.
* Известный долг: `web/src/engine/core.js` и `services.js` перенесены из прежней сборки с короткими именами переменных и без проверки типов (`@ts-nocheck`). Наружу движок смотрит через типизированный `engine/index.ts`; переписывать его на читаемые модули — по частям, под защитой тестов.
* Приложение для Android (Capacitor 7) — отдельный проект `chto-prigotovit-android`; виджеты — копия в `android-extras/`.

Требования хостинга: PHP 7.4+ с pdo_sqlite, mbstring и curl (для ботов), Apache с mod_rewrite (без него страницы работают по адресам с `.php`).

## Настройки (`api/_private/config.php`)

Образец — `config.example.php`. Всё, кроме пароля админки, необязательно.

| Что | Ключ | Зачем |
|---|---|---|
| Магазины доставки | `partners` | Кнопки «Заказать с доставкой» в списке покупок (партнёрские ссылки, например из Admitad). Переходы считаются в статистике. |
| Telegram-бот | `telegram.token`, `telegram.secret` | Токен от @BotFather и секрет от 16 символов. Затем откройте `сайт/bot/telegram.php?setup=СЕКРЕТ`, и вебхук зарегистрируется сам. |
| Навык Алисы | `alice.skill_id`, `alice.name` | В Яндекс Диалогах создайте навык с вебхуком `сайт/bot/alice.php` и укажите его id, чтобы чужие навыки не обращались к адресу. `name` — как навык запускать («Алиса, запусти навык …»): тогда он появится в профиле. Telegram-бот появится в профиле сам после `?setup=`. |
| ИИ на сервере | `intent_provider` | Оставьте `none`: запросы разбирает встроенный движок. |

## Что умеет

* **Помощник**: свободный текст и голос («курица, картошка, без духовки, 30 минут», «скока варить яйца», «мне грустно»), быстрые кнопки и настроения.
* **Под человека**: цели (быстро, экономно, полегче, больше белка, накормить семью), опыт (новичкам — простые блюда и школа готовки), дети, исключения, техника (мультиварка, аэрогриль, микроволновка).
* **Рецепт**: порции, отметки «есть дома», «докупить недостающее», гарнир, КБЖУ, аллергены, заметки, отзывы с фото, похожие блюда.
* **Готовка**: шаги, таймеры со звуком и уведомлением, экран не гаснет, чтение вслух, голосовые команды без рук, второе блюдо параллельно с подсказкой, когда его начинать.
* **Меню на неделю**: без повторов, в будни быстро, готовка на два дня, с учётом целей; блок «Без остатков» показывает, что останется в упаковках, и предлагает блюда, чтобы это доесть, для цели «Экономно» — меню из бюджетных блюд; опрос семьи «что на ужин».
* **Покупки**: по отделам магазина, сколько упаковок брать, купленное одной кнопкой переносится в «Дома».
* **Дома**: продукты со сроками (ставятся сами по типу продукта), «Спасите продукты», рецепты из того, что есть, импорт чека (текст из приложения банка или ФНС разбирается на месте), «осталось от вчера».
* **Семья и устройства**: общее меню, покупки и продукты по ссылке-приглашению; вход на другом устройстве по коду или QR. Без телефонов и почты.
* **Напоминания**: web push со своего сервера — блюдо из меню, продукты, которые пора использовать, или идея на ужин; по воскресеньям — меню на неделю.
* **Поисковики**: страница каждого рецепта, списки, около 1200 страниц «что приготовить из X и Y», sitemap.
* **Telegram и Алиса**: поиск по продуктам, рецепт целиком в чате, голосовая готовка по шагам.
