# Как собрать новый APK «Что приготовить?»

Вы обновляете **тот же проект**, который уже собирали в Android Studio. Новый проект создавать не нужно.
Меняются только файлы сайта внутри приложения и несколько настроек. Весь нативный код остаётся как есть:
голос, озвучка, таймеры и уведомления.

Что понадобится:
- проект приложения, который вы собирали раньше;
- **тот же ключ подписи** (`.jks` или `.keystore`) и пароли к нему. Без этого ключа RuStore не примет
  обновление, а у людей не установится новая версия поверх старой;
- архив `cook-app.zip`, который я прислал (внутри папка `www`);
- архив `cook-hosting.zip` для сайта.

---

## Шаг 0. Сначала обновите сайт на хостинге

Распакуйте `cook-hosting.zip` в папку `cook` на хостинге с заменой файлов, как обычно.
Это нужно сделать до выпуска приложения: новому приложению нужны новые адреса на сервере
(проверка версии каталога, уменьшенные фото).

---

## Шаг 1. Найдите папку с файлами сайта в проекте

Откройте папку проекта в проводнике.

**Вариант А — есть `capacitor.config.json` (или `.ts`) в корне проекта.**
Откройте его и найдите строку `"webDir"`. Чаще всего там написано `"www"` или `"dist"`.
Это и есть папка с сайтом, например `МойПроект/www`.

**Вариант Б — такого файла нет, есть только папка `android`.**
Тогда файлы сайта лежат прямо в `android/app/src/main/assets/public`.

---

## Шаг 2. Замените файлы сайта

**Если у вас вариант А (папка `www`):**
1. Удалите **всё содержимое** папки `www`.
2. Скопируйте туда всё из папки `www` архива `cook-app.zip`: `index.html`, `assets`, `fonts`, `icons`,
   `mascot`, `ocr` и остальное.
3. Откройте терминал в корне проекта (там, где `capacitor.config.json`) и выполните:
   ```
   npx cap sync android
   ```
   Команда сама перенесёт сайт в Android-часть проекта.

**Если у вас вариант Б (только `assets/public`):**
1. Откройте `android/app/src/main/assets/public`.
2. **Не трогайте** файлы `cordova.js`, `cordova_plugins.js`, папку `plugins` и
   `capacitor.config.json`, если они там есть.
3. Удалите остальное: старые `index.html`, `assets` и т. д.
4. Скопируйте туда всё из папки `www` архива.

Проверка: в папке должен лежать `index.html`, а рядом папка `assets` с файлами `app-....js`.

---

## Шаг 3. Откройте проект в Android Studio

`File → Open` → выберите папку `android` вашего проекта.
Дождитесь, пока внизу закончится «Gradle sync» (полоска загрузки).

---

## Шаг 4. Поднимите номер версии

Откройте `android/app/build.gradle` (именно в папке `app`) и найдите блок `defaultConfig`:

```gradle
defaultConfig {
    ...
    versionCode 3          // было, например, 2 — увеличьте на 1
    versionName "2.0"      // это видят люди; новая большая версия — «2.0»
}
```

`versionCode` **обязательно** должен быть больше, чем у версии, которая сейчас в RuStore,
иначе магазин не примет файл. Посмотреть текущий номер можно в консоли RuStore на странице версии.

Если поменяли что-то в `build.gradle`, нажмите вверху **Sync Now**.

---

## Шаг 5. Ссылки из мессенджеров открываются в приложении

Откройте `android/app/src/main/AndroidManifest.xml`. Найдите `<activity` с
`android:name=".MainActivity"`. Внутри него уже есть `<intent-filter>` с `MAIN` и `LAUNCHER`.
**Ниже него** (внутри того же `<activity>`) добавьте второй:

```xml
<intent-filter android:autoVerify="true">
    <action android:name="android.intent.action.VIEW" />
    <category android:name="android.intent.category.DEFAULT" />
    <category android:name="android.intent.category.BROWSABLE" />
    <data android:scheme="https" android:host="treas.su" android:pathPrefix="/cook" />
</intent-filter>
```

Потом, на шаге 9, выложите на хостинг файл, который подтверждает, что это ваше приложение.

---

## Шаг 6. Разрешения

В том же `AndroidManifest.xml`, **над** `<application`, проверьте, что есть эти строки.
Каких-то может уже не хватать, тогда добавьте:

```xml
<uses-permission android:name="android.permission.INTERNET" />
<uses-permission android:name="android.permission.RECORD_AUDIO" />
<uses-permission android:name="android.permission.CAMERA" />
<uses-permission android:name="android.permission.POST_NOTIFICATIONS" />
<uses-permission android:name="android.permission.VIBRATE" />
<uses-permission android:name="android.permission.WAKE_LOCK" />
<uses-permission android:name="android.permission.SCHEDULE_EXACT_ALARM" />
```

`CAMERA` нужна для сканирования штрихкода продуктов. Если её раньше не было, при входе в
«Мои продукты» и сканировании телефон спросит разрешение.

---

## Шаг 7. Размер текста не увеличивается дважды

Откройте `android/app/src/main/java/.../MainActivity.java` (путь зависит от названия пакета,
например `java/su/treas/cook/MainActivity.java`).

Сейчас там примерно так:

```java
public class MainActivity extends BridgeActivity {
    ...
}
```

Добавьте внутрь класса метод `onStart` и одну строку `import` наверх файла.
Всё, что уже было внутри класса (например, регистрацию вашего плагина), оставьте как есть.

```java
import android.os.Bundle;            // если уже есть — не дублируйте
import com.getcapacitor.BridgeActivity;

public class MainActivity extends BridgeActivity {

    // ... то, что уже было (registerPlugin и т. п.) — не трогать ...

    @Override
    public void onStart() {
        super.onStart();
        // Крупный шрифт включается только «Размером текста» в приложении, а не дважды
        getBridge().getWebView().getSettings().setTextZoom(100);
    }
}
```

Если `onStart` в файле уже есть, просто добавьте строку `getBridge()...setTextZoom(100);` после `super.onStart();`.

Если файл называется `MainActivity.kt` (Kotlin):

```kotlin
override fun onStart() {
    super.onStart()
    bridge.webView.settings.textZoom = 100
}
```

## Шаг 8. Соберите подписанный APK

1. В меню: **Build → Generate Signed App Bundle / APK…**
2. Выберите **APK** → Next.
3. **Key store path** — укажите **тот же файл ключа**, что и в прошлый раз. Введите пароль ключа,
   выберите тот же **Key alias** и его пароль. Если отмечено «Remember passwords», всё уже будет заполнено.
4. Next → **Build Variants: release** → Create (или Finish).
5. Через минуту-две внизу появится уведомление «APK(s) generated» → нажмите **locate**.
   Файл обычно лежит в `android/app/release/app-release.apk`.

Если хотите, можно собрать и **App Bundle (.aab)**: RuStore его тоже принимает. Но APK проще,
потому что его же можно сразу поставить на свой телефон для проверки.

---

## Шаг 9. Файл на хостинге для ссылок

### Узнайте отпечаток ключа

**Способ попроще — в Android Studio.** Справа откройте вкладку **Gradle** → `app` → `Tasks` →
`android` → двойной клик **signingReport**. Внизу появится текст. Найдите блок `Variant: release`
и строку **SHA-256:** `AB:CD:12:...`. Скопируйте её.

Если в release-блоке пусто, используйте способ через терминал (Windows, в папке с ключом):

```
keytool -list -v -keystore ваш_ключ.jks -alias ваш_alias
```

Скопируйте строку `SHA256: ...`.

### Узнайте имя пакета

Это `applicationId` в `android/app/build.gradle`, например `su.treas.cook`.

### Создайте файл

На хостинге, **в корне сайта** treas.su, а не в папке `cook`, создайте папку `.well-known`,
в ней файл `assetlinks.json`:

```json
[{
  "relation": ["delegate_permission/common.handle_all_urls"],
  "target": {
    "namespace": "android_app",
    "package_name": "ВАШ_applicationId",
    "sha256_cert_fingerprints": ["ВАШ:SHA-256:ОТПЕЧАТОК"]
  }
}]
```

Проверка: откройте в браузере `https://treas.su/.well-known/assetlinks.json`. Должен показаться этот текст.

## Шаг 10. Проверьте на своём телефоне

Поставьте `app-release.apk` поверх старой версии: перекиньте файл на телефон и откройте его,
или подключите телефон кабелем и нажмите в Android Studio ▶ Run с выбранным release.
**Не удаляйте старую версию перед установкой**, иначе пропадут ваши данные в ней.

Проверьте по списку:

- [ ] Приложение открывается, на главной новые экраны: «На сегодня», «Вы смотрели».
- [ ] Включите режим полёта и перезапустите приложение: открывается, рецепты листаются.
- [ ] «Назад» на телефоне: закрывает окошко → рецепт → возвращает на Главную → с Главной сворачивает.
- [ ] Шеф: «есть курица и картошка» — ответ с рецептами. Микрофон работает.
- [ ] Рецепт → «Начать готовить» → таймер на шаге. Погасите экран кнопкой и дождитесь сигнала.
- [ ] Покупки → «Я в магазине» → смахнуть продукт вправо.
- [ ] Покупки → «Добавить» → микрофон → «молоко, хлеб, десяток яиц».
- [ ] Пришлите себе в мессенджер ссылку на рецепт (`https://treas.su/cook/recipe/...`) и нажмите на неё:
      должно открыться приложение на этом рецепте.
      Если открывается браузер: Настройки телефона → Приложения → «Что приготовить?» →
      «Открывать по умолчанию» → включить ссылки treas.su. Если там нет пункта «treas.su»,
      значит файл `assetlinks.json` ещё не виден или отпечаток не совпадает.
- [ ] «Заказать с доставкой» и ссылки в «Документах» открываются в браузере телефона.
- [ ] Профиль → «Размер текста» → «Крупный»: всё крупнее и ничего не разъезжается.

---

## Шаг 11. Загрузите в RuStore

1. Консоль RuStore → ваше приложение → **Новая версия** → загрузите `app-release.apk`.
2. Поле «Что нового» — текст из `ТЕКСТЫ-RuStore.txt`.
3. Раздел оформления: удалите старые скриншоты и загрузите 8 новых по порядку (01–08).
   Обновите полное и короткое описание.
4. Отправьте на модерацию.

---

## Если что-то пошло не так

| Что видите | Почему и что делать |
|---|---|
| Белый экран при запуске | В папке сайта нет `index.html` или он не в той папке. Повторите шаг 2; для варианта А не забудьте `npx cap sync android`. |
| Открывается старая версия | Не выполнили `npx cap sync android` (вариант А) или скопировали в другую папку. После копирования в Android Studio: **Build → Clean Project**, затем собрать снова. |
| «Приложение не установлено» поверх старого | APK подписан другим ключом. Нужен тот же ключ, что и раньше. |
| RuStore не принимает файл | `versionCode` не больше прежнего (шаг 4) или файл не подписан release-ключом. |
| Ссылки открываются в браузере | Шаг 9: проверьте, что `assetlinks.json` открывается в браузере, имя пакета и отпечаток верные. После исправления переустановите приложение. |
| Таймер не звенит при погашенном экране | При первом таймере разрешите уведомления. Для Android 12+ включите «Будильники и напоминания» для приложения в настройках телефона. |
| Ошибка сборки про `setTextZoom` / `getBridge` | Метод `onStart` попал не внутрь класса `MainActivity` или не хватает `import`. Пришлите мне текст ошибки и файл `MainActivity`. |

Если на любом шаге что-то не сходится, пришлите скриншот или текст ошибки. Можно прислать и
файлы `AndroidManifest.xml`, `MainActivity` и `build.gradle` — я сам их поправлю.
