Каталог рецептов «Что приготовить?»

Каждый файл *.json в этой папке — партия: в нём есть продукты (ingredients) и рецепты (recipes).
Сайт читает все файлы по порядку имени (01-..., 02-..., 03-...) и складывает их вместе.

Как добавить партию:
1. Получите от нейросети JSON по ТЗ и сохраните как, например, 02-supy.json (кодировка UTF-8).
2. Загрузите файл в эту папку на хостинге (data/catalog/).
3. Откройте https://ваш-сайт/?check=1 — там видно, сколько рецептов принято и какие ошибки нашлись.
   Записи с ошибками на сайт не попадают, остальные работают сразу, без пересборки.

Не редактируйте 01-base.json без необходимости — это первые рецепты, на них опираются проверки.
Продукт можно использовать в рецепте из любого файла: id продуктов общие для всех партий.

Техника в рецептах (appliances): pan, pot, oven, blender, multicooker, airfryer, microwave.
Рецепты для мультиварки, аэрогриля и микроволновки видят те, у кого эта техника отмечена в профиле, или кто прямо попросил («в аэрогриле»).
В totalMinutes указывайте время самой готовки; разморозку и маринование на ночь лучше писать в советах (tips), иначе блюдо не попадёт в быстрые.
